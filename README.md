# JARVIS for Bazzite

This repository is a **JARVIS layer for an already installed Bazzite / Fedora Atomic
system**. It is not a custom OS image.

Start here: **[jarvis-os/README.md](jarvis-os/README.md)**

```bash
cd jarvis-os
./install.sh
```

Then open **JARVIS Assistant** from the app grid, or say **“Jarvis, volume up”**
after pressing **Super+Alt+J**.

Full instructions: [jarvis-os/docs/INSTALL.md](jarvis-os/docs/INSTALL.md) ·
[voice control](jarvis-os/docs/VOICE-CONTROL.md) ·
[quickstart](jarvis-os/QUICKSTART.md)
